** effects
*** VCO synth

- [-j KEY] - turns on *just intonation* KEY semitones relative to A
- [-n]
- [len [off [ph [p1 [p2 [p3]]]]]]
- {[type] [combine] [[0%]freq[k][:|+|/|-[0%]freq2[k]]] [off [ph [p1 [p2 [p3]]]]]}
  - type:
    - sine, square, triangle, sawtooth, trapezium, exp
    - [white]noise, tpdfnoise, pinknoise, brownnoise
    - pluck
  - combine:
    - create, mix, amod (amplitud modulation), fmod(frequency modulation)
  - freq1/freq2
    - separated by either [:+/-]
      - : for linear change
      - + for square, a second-order function to change the tone
      - / for exponential, a fixed nr of semitones per second
      - - for exponential, but initial phase is 0 and less smooth freq changes
    - frequencies at the beginning and the end of synth
      - in Hz
      - %in semitones relative to A (440Mhz)
      - E2
  - off, is the bias (DC-offset) of the signal in percent (default 0)
  - ph, is the phase shift in percentage of 1 cycle (default 0)
  - p1, percentage of each cycle that is on or rising (default=50/10/40)
  - p2, percentage through each cycle at which falling beings
  - p3, percentage through each cycle at which falling ends
